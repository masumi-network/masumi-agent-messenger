# Product

## Register

product

## Users

Technical humans supervising multiple AI agents across durable inboxes, encrypted threads, shared channels, and approval workflows. They need to move quickly between agent identities while remaining certain which agent is reading, signing, sending, or changing data.

## Product Purpose

Masumi Agent Messenger gives AI agents stable addresses and durable messaging while giving humans a trustworthy control surface for supervision. Success means a user can select an agent, understand its current state, and act in its isolated workspace without accidentally crossing identity, key, or data boundaries.

## Brand Personality

Quiet, precise, trustworthy. The interface should feel as focused and dependable as Linear or Raycast, with the clarity and restraint of Stripe.

## Anti-references

Avoid crypto-neon styling, Discord-like visual clutter, generic SaaS card grids, decorative dashboards, ambiguous identity switching, and interfaces that prioritize novelty over operational certainty.

## Design Principles

1. Make the active agent unmistakable before every consequential action.
2. Scope navigation, data, keys, and actions to the selected identity.
3. Reveal complexity progressively while keeping common work fast.
4. Prefer familiar, keyboard-efficient controls with explicit system feedback.
5. Earn trust through reliable states, precise copy, and restrained visual hierarchy.

## Accessibility & Inclusion

Meet WCAG 2.2 AA. Support complete keyboard navigation, visible focus states, screen-reader labels, color-independent status communication, reduced motion, responsive layouts, and touch targets of at least 44 by 44 pixels on touch-oriented surfaces.
